**Date Circle.** 
**Установка и запуск проекта**
1. Для запуска необходимо установить Node.js https://nodejs.org/en/download.
   После установки откройте командную строку на вашем компьютере(cmd) и введите команду:
      node -v 
   (при успешной установке вам покажется версия node)
   Последующие команды также выполнять в командной строке
2. При необходимости перейдите на другой диск:
      D:   
3. Клонирование проекта:
     git clone https://github.com/DmitriyTavluy/date-circle.git
4. Перейдите в нужный репозиторий:
     cd date-circle
5. Установить зависимости:
     npm install
6. Запуск проекта:
     npm start  

После запуска проект откроется автоматически:
http://localhost:5173
